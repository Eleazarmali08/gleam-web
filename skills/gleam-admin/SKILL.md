# SKILL: gleam-admin — Update Gleam Admin Panel

## Purpose

## Rules (must-follow)
1. Sidebar pakai: `document.getElementById('sidebar-container').innerHTML = GleamTheme.renderSidebar('pageName')`
2. Init theme: `GleamTheme.init()`
3. Check auth: `await GleamTheme.checkAuth()`
4. Warna text: `style="color: var(--text)"`
5. Warna secondary: `style="color: var(--text-secondary)"`
6. Background: `style="background: var(--bg)"`
7. Card: `class="glass-card"`
8. Button gold: `class="btn-gold"`
9. Ikon pakai SVG stroke (bukan emoji)
10. Format harga: `GleamTheme.formatPrice()`
11. Format tanggal: `GleamTheme.formatDate()`
12. Status badge: `GleamTheme.statusBadge()`

## Recommended workflow
1. Open the target admin page.
2. Ensure the page calls `GleamTheme.init()` early (preferably in a shared header or inline script).
3. Run `await GleamTheme.checkAuth()` before rendering protected content.
4. Replace inline colors/text with the `var(--...)` CSS variables above.
5. Wrap data containers in `div` with `class="glass-card"` where applicable.
6. Replace raw price/date display with `GleamTheme.formatPrice(value)` / `GleamTheme.formatDate(value)`.
7. Use `GleamTheme.statusBadge(status)` to render status indicators.
8. Use SVG icons with `stroke` attributes for all icons; avoid emoji.

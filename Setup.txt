
## ⚙️ Setup

1. Upload semua file ke hosting PHP
2. Ganti `YOUR_ANON_KEY` dan `YOUR_SERVICE_ROLE_KEY` di:
   - `api/config.php`
   - `admin/login.html`
   - `admin/dashboard.html`
3. Setting `.htaccess` untuk rewrite rules
4. Buka `https://domain-anda.com`

## 🔐 Default Admin

Buat admin pertama via Supabase Dashboard:
1. Authentication → Users → Add User
2. Table Editor → profiles → Edit role menjadi `admin`
